# Project Documentation Index

This directory organizes all architectural specifications, design system guides, case study templates, and implementation tracking logs for the portfolio.

---

## 📂 Directory Layout

### 1. [`architecture/`](./architecture/)

* [`benaih_portfolio_master_plan.md`](./architecture/benaih_portfolio_master_plan.md) — Master product vision, project tracks, feature specifications, and mathematical foundations.
* [`TECHNICAL_STRATEGY.md`](./architecture/TECHNICAL_STRATEGY.md) — Technical implementation strategy, R3F scenes, routing decisions, and library integrations.

### 2. [`design-system/`](./design-system/)

* [`DESIGN_SYSTEM.md`](./design-system/DESIGN_SYSTEM.md) — Typography scales, color palette, glassmorphism tokens, and spatial grids.

* [`UI_COMPONENTS_DOCUMENTATION.md`](./design-system/UI_COMPONENTS_DOCUMENTATION.md) — Reusable UI component specifications, props, and interaction patterns.

* [`DELIVERY_CHECKLIST.md`](./tracking-and-delivery/DELIVERY_CHECKLIST.md) — Quality assurance and verification checklist.
